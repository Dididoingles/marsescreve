Termos de Uso e Privacidade

Última atualização: Novembro de 2026

Bem-vindo ao Ajudante. Esta ferramenta foi criada para ajudar estudantes a praticar a escrita em inglês, identificando palavras em português e sugerindo correções. Antes de usar, por favor, leia atentamente como tratamos os seus dados.

1. Sobre o Uso da Ferramenta

O Ajudante é uma ferramenta gratuita e de caráter educacional. Ao utilizá-lo, você concorda que:

  • O texto que você escreve é de sua inteira responsabilidade.
  • A ferramenta não armazena permanentemente o seu texto em nossos servidores. O processamento é feito em tempo real e o texto é descartado logo após a resposta.
  • O uso é destinado a fins de aprendizado e aprimoramento da escrita.

2. Como os seus dados são tratados (Privacidade)

Para que o Ajudante funcione, o texto que você digita é enviado para dois serviços externos. Veja como cada um lida com os seus dados:

LanguageTool (Verificação Gramatical)
Quando você clica no ícone de verificação, o texto é enviado para a API do LanguageTool. Segundo a política deles:
  • O serviço está em conformidade com o GDPR (regulamento europeu de proteção de dados).
  • Nenhum texto enviado para a API é armazenado pelos servidores deles para garantir total privacidade.
  • Os servidores ficam na Alemanha.
Inteligência Artificial
Quando você usa a função de "Traduzir/Resgatar", o texto é enviado para a API do Groq (que processa o modelo de IA). Segundo a política deles:
  • A Groq não utiliza os seus dados para treinar modelos de IA.
  • Por padrão, a Groq não retém os dados de entrada/saída (seu texto) para requisições de inferência. Eles são processados e descartados.
  • Exceção: Em casos de falha técnica ou suspeita de abuso (como sobrecarga do sistema), a Groq pode reter logs temporários por até 30 dias para investigação.
  • O processamento ocorre em servidores nos Estados Unidos.

3. Segurança e Limitação de Responsabilidade

Nós nos esforçamos para proteger a sua privacidade, mas é importante entender que:

  • Como o Ajudante é uma ferramenta gratuita e de código aberto, não podemos garantir disponibilidade ininterrupta.
  • O serviço é fornecido "como está". Não nos responsabilizamos por eventuais imprecisões nas sugestões de tradução ou correção geradas pela IA.
  • Não coletamos dados pessoais identificáveis (como nome, e-mail ou IP) de forma intencional. A única informação que fica salva no seu navegador é um ID aleatório (para controle de uso), que não contém dados pessoais.

4. Direitos do Usuário (LGPD)

Como não armazenamos o seu texto ou dados pessoais em nossos servidores, não há dados para excluir ou corrigir do nosso lado. Se você tiver dúvidas sobre como o LanguageTool ou a Groq tratam seus dados, recomendamos consultar as políticas de privacidade oficiais deles.
